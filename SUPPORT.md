# Support

AGID is a pre-1.0 open-source project. Support is best effort and should happen
in public whenever it is safe.

## Use GitHub Issues For

- reproducible bugs using synthetic or redacted data;
- documentation gaps;
- SDK parity failures;
- address-format or country-pack corrections;
- accessibility and UI usability problems;
- local install, build, and self-hosting questions.

## Do Not Post Private Data

Do not include real addresses, recipient names, phone numbers, unit/room details,
proof codes, witness material, private keys, API keys, shipping labels, identity
documents, or production tenant data in issues, discussions, screenshots, logs,
or attachments.

Use synthetic examples such as:

```text
AGID: JP00TEST0001
alias: addr_alias_demo_001
commitment: commit_demo_001
receipt: rcpt_demo_001
```

## Security Reports

For security or privacy issues, follow [SECURITY.md](SECURITY.md). If private
vulnerability reporting is not configured, open a minimal issue titled
`Security contact needed` without exploit details or private data.

## Expected Response

- Critical security/privacy reports: best effort triage within 7 days.
- Bugs and documentation issues: best effort review when maintainers are
  available.
- Large feature proposals: may be redirected to the roadmap or a design issue.

The project does not currently provide paid production support.
